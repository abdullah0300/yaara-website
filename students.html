Does everyone in the group need an account?

You can keep personal records for contacts without connected accounts. For someone else to access shared records, they need the appropriate connection or group access.

Can I add something when campus Wi-Fi drops?

You can add records offline. Queued changes sync when you’re connected again; another person’s phone won’t receive an update while you’re offline.

Can I download Yaara now?

Yaara is 100% free to use on Android. You can install Yaara directly from the Google Play Store using the download buttons on this page.

Can we split college group project costs equally in Yaara?

Yes. Create a dedicated group for your project team, add expenses like printing, poster board, or materials with the payer, and Yaara calculates each member’s exact share automatically.

How do student roommates split rent and shared flat bills?

Set up a flatmates group to track monthly rent, electricity, Wi-Fi, and groceries. Yaara records who paid and tracks partial repayments so everyone stays on the same page.
