# Yaara website

Complete static website source: seven pages, locally bundled images and fonts, CSS and JavaScript. No build step or package installation is required.

## Run locally
Extract this ZIP, open a terminal in the `Yaara-Website` folder and run:

    python3 -m http.server 8000

Then open http://localhost:8000 in your browser. You can also open index.html directly for a quick preview.

## Files
- index.html: main landing page
- friends.html, couples.html, students.html, housemates.html, travel.html, partners.html: audience pages
- assets/: bundled imagery, brand assets and fonts
- *.css and *.js: editable styles and scripts
- docs/: project notes and image-generation prompts

Upload the folder contents to any static web host. Update canonical and Open Graph URLs in the HTML when using your own domain.

Phone screens are labelled illustrative previews; they are not screenshots of the shipped app. Demo interactions on the website do not transfer money.
